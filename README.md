# GOST-S-LEARNING-BOT-TELEGRAM
# ГОСТ-бот — преподаватель ЕСКД для конструкторов  Telegram-бот учит требованиям ЕСКД к чертежам. Он задаёт вопросы с картинками и вариантами ответа, а после ответа даёт пояснение и ссылку на пункт стандарта.  **Стандарты:** ГОСТ 2.301, 2.303, 2.305, 2.306, 2.307, ГОСТ Р 2.104-2023, ГОСТ Р 2.105-2019, ГОСТ 2.311, 2.313, 2.315, 2.402.
