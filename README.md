# ГОСТ-бот — преподаватель ЕСКД для конструкторов

Telegram-бот учит требованиям ЕСКД к чертежам. Он задаёт вопросы с картинками и вариантами ответа, а после ответа даёт пояснение и ссылку на пункт стандарта.

**Стандарты:** ГОСТ 2.301, 2.303, 2.305, 2.306, 2.307, ГОСТ Р 2.104-2023, ГОСТ Р 2.105-2019, ГОСТ 2.311, 2.313, 2.315, 2.402. В базе более 500 вопросов и около 60 чертежей.

## Что умеет

- **📚 Учить ГОСТ.** Выбираете стандарт, читаете шпаргалку и проходите тренировку из 10 вопросов. Сначала идут новые вопросы и ошибки.
- **📝 Экзамен.** 20 вопросов по всем стандартам, разбор в конце, кнопка «Разобрать ошибки с пояснениями».
- **🔁 Повторение.** Вопросы, в которых была ошибка, возвращаются через 1, 3, 7, 14 и 30 дней, пока не закрепятся.
- **📊 Прогресс.** Сколько вопросов освоено по каждому стандарту, точность ответов, лучший экзамен.
- **⚙️ Настройки.** «Вопрос дня» по утрам и сброс прогресса.
- **⚠️ Ошибка в вопросе.** Кнопка под каждым пояснением. Конструктор выбирает причину («неверный ответ», «картинка не соответствует», «непонятно») или пишет своими словами — администратору сразу приходит сообщение с номером вопроса, текстом и ответом из базы.
- **Команды администратора:**
  - `/stats` — сводка по всем конструкторам;
  - `/reload` — перечитать базу вопросов без перезапуска бота;
  - `/reports` — открытые жалобы на вопросы;
  - `/fixed 305-101` — отметить жалобы на вопрос исправленными.
- **Код доступа.** Если задан, бот отвечает только тем, кто его ввёл.

## Установка на Windows

1. Установите **Python 3.10+** с python.org. При установке отметьте «Add python.exe to PATH».
2. Создайте бота:
   - в Telegram напишите **@BotFather** → `/newbot`;
   - придумайте имя;
   - скопируйте токен.
3. Распакуйте папку бота куда удобно, например `C:\Users\evgen\Documents\ГОСТ-бот`.
4. Дважды щёлкните **install.bat**. Он поставит пакеты (requests, PyYAML) и создаст файл `.env`.
5. Откройте `.env` в Блокноте и заполните поля:
   - `BOT_TOKEN` — токен от BotFather;
   - `ADMIN_IDS` — ваш Telegram ID (узнать у **@userinfobot**);
   - `ACCESS_CODE` — код для конструкторов, если бот должен быть закрытым.
6. Дважды щёлкните **run_bot.bat** и напишите боту `/start`. Если всё работает, закройте окно.
7. Включите автозапуск: откройте командную строку в папке бота и выполните
   ```
   python install_autostart.py
   ```
   Бот запустится в фоне без окна и будет стартовать сам при каждом входе в Windows. Если бот упадёт или пропадёт интернет, сторож (`run_forever.py`) перезапустит его. Отключить автозапуск: `python install_autostart.py remove`.

> Бот работает, пока компьютер включён и не спит. Если ПК уходит в сон, проверьте: «Параметры → Система → Питание → Спящий режим → Никогда».

**Перезапуск** (например, после обновления файлов): дважды щёлкните `restart_bot.bat`. Он остановит фоновый бот этой папки и запустит его заново, другие программы Python не затрагиваются. Окно `run_bot.bat`, если оно открыто, закройте сами.

Журналы: `bot.log` (работа бота, токен в нём скрыт) и `watchdog.log` (только перезапуски).

### Если бот не отвечает

- **В журнале «Telegram 409».** С этим токеном одновременно работают две копии бота. Начиная с версии 2 вторая копия на том же компьютере просто не запустится: окно `run_bot.bat` сообщит, что бот уже работает в фоне. Если 409 остаётся, бот с тем же токеном запущен на другом компьютере — остановите его там.
- **Нет интернета при включении ПК.** Бот ждёт сеть и подключается сам, ничего делать не нужно.
- **«Вопрос дня» не пришёл в 9:00.** Если сети не было или ПК был выключен, вопрос дня придёт, как только бот снова на связи, но не позже 21:00. Прогресс пользователей хранится в `bot.sqlite3`. Его не удаляйте, а при переносе бота копируйте вместе с ним.

## Как добавить или исправить вопросы

Вопросы лежат в `data/questions/2_XXX.yaml`, по одному файлу на стандарт. Пример:

```yaml
- id: "303-18"                 # уникальный номер
  gost: "2.303"                # код стандарта из data/gosts.yaml
  ref: "ГОСТ 2.303-68, п. 11"  # ссылка, показывается после ответа
  image: "303_centers.png"     # картинка из папки images (можно не указывать — будет титульная)
  q: "Текст вопроса?"
  options: ["Верный", "Неверный 1", "Неверный 2", "Неверный 3"]
  answer: 0                    # номер верного варианта, считая с 0
  explain: "Короткое пояснение."
  level: 1                     # 1 — простой, 2 — средний, 3 — сложный (необязательно)
  fixed: true                  # только если варианты — буквы А/Б/В с картинки (не перемешивать)
```

После правки отправьте боту `/reload`. Если в файле ошибка, бот её покажет и оставит старую базу.

Шпаргалки и статусы стандартов лежат в `data/gosts.yaml`.

## Картинки

Все чертежи нарисованы программно (`tools/figs/*.py`) по нормам стандартов: толщины и штрихи линий в миллиметрах по ГОСТ 2.303. Перерисовать после правки:

```
pip install matplotlib pillow
python tools/gen_images.py          # все
python tools/gen_images.py 305      # только для ГОСТ 2.305
```

## Статус стандартов (на октябрь 2026)

- **ГОСТ 2.301, 2.303, 2.305, 2.306.** В августе–сентябре 2026 г. утверждены ГОСТ Р 2.301-2026, 2.303-2026, 2.305-2026, 2.306-2026. Старые стандарты применяются в РФ до 01.10.2027. Тексты новых пока не опубликованы, поэтому вопросы составлены по действующим редакциям. Когда тексты появятся, банк нужно сверить.
- **ГОСТ Р 2.104-2023** — с 01.03.2024 вместо ГОСТ 2.104-2006, который заменил ГОСТ 2.104-68.
- **ГОСТ Р 2.105-2019** — с 01.02.2020.
- **ГОСТ 2.307-2011, 2.311-68, 2.313-82, 2.315-68, 2.402-68** — действуют.

## Проверка

```
python tests/test_flow.py
```

Тест прогоняет все сценарии на поддельном Telegram: тренировку, экзамен, повторение, вопрос дня, код доступа и админ-команды. Заодно он проверяет, что каждый вопрос укладывается в лимиты Telegram.
