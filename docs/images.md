# Каталог картинок (папка images/)

Что изображено на каждой картинке и что означают метки. По этому списку пишут вопросы к картинкам.
Красные цифры в кружках и буквы А/Б/В/Г — метки вопроса. Синие подписи — пояснения, это не элементы чертежа.
Карточки `card_2_XXX.png` — титульные карточки стандартов. Их показывают у вопросов без своей картинки (поле image пустое).
